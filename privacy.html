Privacy policy

Last updated: 24 November 2026

Jerry is a personal assistant that I run on my own computer for my own use. It has one user: me. This page explains how it handles Google user data.

What data it accesses

Jerry asks for read-only access to my Google Calendar (scope calendar.readonly). It reads event titles, times, locations and descriptions from my own calendars. It does not access any other Google data and cannot create, change or delete events.

How the data is used

Calendar data is only used to answer my own questions about my schedule, in my private chat with the assistant. It is not used for advertising, profiling or any other purpose.

Storage and sharing

The access token is stored encrypted on my own computer. Calendar data is fetched when needed and is not copied to any other server or database, apart from being processed by the AI model that writes the assistant's replies. It is not sold, shared with or transferred to anyone else.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
